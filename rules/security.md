# セキュリティ要件

このドキュメントは、全プロジェクトで守るべき基本的なセキュリティ要件です。

## 適用条件

言語・プラットフォームを問わず、すべてのプロジェクトに適用する。

---

## 1. シークレット情報の管理

- パスワード、API キー、トークンなどの秘密情報はコードに埋め込まない
- 秘密情報は環境変数または Keychain から読み込む
- .env ファイルなどの秘密情報ファイルは .gitignore で管理する

## 2. ネットワーク通信

- HTTP ではなく HTTPS を使用する
- 外部 API と通信する場合は、SSL/TLS 証明書を検証する

## 3. 入力値の検証

- ユーザー入力や外部データは検証してから使用する
- 型チェック、長さチェック、形式チェックを実施する

## 4. ログ出力

- パスワード、トークン、個人情報をログに出力しない
- 本番環境ではデバッグログを無効化する

## 5. 依存関係

- サードパーティライブラリは信頼できるソースから導入する
- セキュリティアップデートが公開されたら速やかに適用する

---

## レビューチェックリスト

- [ ] パスワード・API キー・トークンがコードに埋め込まれていないか
- [ ] 秘密情報が環境変数または Keychain から読み込まれているか
- [ ] 秘密情報を含むファイルが `.gitignore` に登録されているか
- [ ] 外部通信が HTTPS になっているか（HTTP のエンドポイントが残っていないか）
- [ ] SSL/TLS 証明書の検証を無効化していないか
- [ ] ユーザー入力・外部データに型・長さ・形式の検証があるか
- [ ] パスワード・トークン・個人情報がログに出力されていないか
- [ ] 本番ビルドでデバッグログが無効化されているか
- [ ] 追加した依存が信頼できるソースのものか

---

**注:** このドキュメントは基本的な要件です。プロジェクトの成長に応じて拡張してください。
